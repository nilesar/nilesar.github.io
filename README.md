# Nilendu Adhikary — GitHub Pages Portfolio

A lightweight, responsive personal website built with plain HTML and CSS. No build tools, package installation, or framework required.

## Preview locally
Open `index.html` in a browser.

## Publish at `https://nilesar.github.io/`
1. Create a GitHub repository named exactly `nilesar.github.io` under the account `nilesar`.
2. Upload `index.html`, the `assets/` folder, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait a minute or two, then visit `https://nilesar.github.io/`.

## Easy edits
- Main content and styling are all in `index.html`.
- Replace `assets/Nilendu_Adhikary_CV.pdf` whenever your CV changes, keeping the same filename so the CV links continue to work.
- Project cards intentionally do not claim repository links that were not supplied. Add links to the relevant project titles once you have the public repository URLs.
- Check the education, publication, and contact details before publishing.
